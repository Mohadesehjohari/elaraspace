# Eli VRM asset drop

Upload the exported file **eli-female-v1.vrm** into this directory by using GitHub's **Add file → Upload files**. Keep the file name exactly as written. This folder's README deliberately does not include a model. The live renderer uses this URL after the asset is published: `assets/avatar/bases/eli-female-v1.vrm`.

No file named `eli.vroid` should be added to this public directory. Original VRoid editable source stays private. Browser-visible .vrm assets remain extractable by visitors.

Current viewer is desktop preview with VRM idle motion + full-outfit swap placeholders. Rigged single-garment mixing is not implemented.
