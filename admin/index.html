تنظیمات Elara AI

کاربر فقط برند و نام نمایشی Elara را می‌بیند؛ شناسهٔ فنی مدل و Token در پنل مدیر/سرور می‌ماند.

مدل‌ها

نامی که کاربر می‌بیند می‌تواند Elara-style باشد؛ Technical Model ID فقط اینجا نگه‌داری می‌شود.

Tokenها و مدیریت بار

Token کامل فقط همین یک‌بار از فرم به Backend امن ارسال و با AES-256-GCM خارج public_html ذخیره می‌شود؛ بعداً فقط مقدار ماسک‌شده دیده می‌شود.

هویت و امنیت پاسخ

System policy سرور Elara را به‌عنوان شخصیت محصول حفظ می‌کند، Secret/System Prompt/route را افشا نمی‌کند و جزئیات Provider را در استفادهٔ عادی داوطلبانه نمایش نمی‌دهد. اگر کاربر مستقیم دربارهٔ سازندهٔ مدل پایه بپرسد، پاسخ نباید به‌دروغ ادعا کند مدل پایه توسط Elara ساخته شده است.
