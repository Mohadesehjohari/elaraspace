# Avatar reference

Canonical visual references are the approved Female and Male turnaround sheets from 2026-10-05.

When binary reference images are added to the repository, use stable names:
- `female-turnaround-approved-2026-10-05.png`
- `male-turnaround-approved-2026-10-05.png`

Do not replace these silently. A new visual direction requires an explicit art-direction revision in the canonical avatar roadmap.
