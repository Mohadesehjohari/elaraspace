# Elara Space — گزارش اجرایی فاز طرح‌های تصویری تأییدشده

تاریخ: ۲۱ سپتامبر ۲۰۲۶. مرجع اصلی سه تصویر کاربر است؛ ثبت این سند هرگز به‌معنی تست یا آماده‌بودن انتشار نیست.

## ممیزی قبل از تغییر

**از قبل موجود:** تسک/توضیح کوتاه و بلند/اولویت و تاریخ/تکرار/تاریخچهٔ تکمیل، پوشه و تگ، عادت و هدف، Focus/Reset و Session، کتابخانهٔ عمومی، لایتنر و XP/مأموریت، دوستان/رنکینگ، Firebase Auth/Firestore، Drawer حساب و Dialog سفارشی، و `admin/index.html`. وجود کد به‌معنی تست واقعی نیست.

**نیازمند اصلاح:** ناوبری پنج‌تایی مصوب، چیدمان و استیکرهای سه‌بعدی، صفحهٔ یکپارچهٔ زبان، افزودن پوشه/تگ با Input کنار همان فیلد، ویرایش مرکزی پروفایل، کمد و بنر، رنگ P1 تا P4، متن دوستان، ردیف‌های تسک دسکتاپ و فونت.

**هنوز پیاده‌سازی‌نشده در شروع فاز:** انتقال PNG آواتار/فریم/لوگوی اصلی از ریپوی عمومی به `assets/` ریپوی توسعه، اعتبارسنجی سمت سرور برای کمد، Course backend، کتاب زبان همگام‌شونده در Firebase، انتشار Rules و ZIP تأییدشدهٔ کل سایت.

## واقعاً کدنویسی و Commit شده در `main`

- `approved-visual.css` و `approved-tuning.css`: پوستهٔ سرمه‌ای/بنفش، کارت و Grid دو ستونی گوشی، پنج ورودی پایین، زبان/کمد، اولویت‌های رنگی و عرض متعادل اکشن‌های تسک، Scrim نیمه‌شفاف، تنظیمات روشن/تاریک و کاهش حرکت.
- `approved-visual.js`: پنج مسیر خانه/تسک/زبان/کتابخانه/رنکینگ، کارت‌های خانۀ واقعی و Focus، صفحهٔ زبان شامل لایتنر موجود، کتاب زبان جدا از کتابخانۀ عمومی و گزارش بر پایهٔ دادهٔ محلی واقعی، Course با وضعیت «در راه»، افزودن درجا برای پوشه/تگ، کمد با پیش‌نمایش/قفل نمایشی و سه بنر SVG. کتاب زبان و انتخاب کمد فعلاً در localStorage مخصوص UID دستگاه ذخیره می‌شوند، نه Firebase.
- `approved-focus-dialog.js`: دکمهٔ تمرکز از Home همان کنترل‌ها و تایمر واقعی Focus را در Dialog مرکزی باز می‌کند و بعد از بستن به جای قبلی برمی‌گرداند. جای تب اصلی Focus بدون تأیید کاربر عوض نشده است.
- `approved-runtime.js`: کنترل submit و وضعیت خطای ذخیرهٔ مستقل پروفایل با API موجود، بررسی FontFace بارگذاری‌شده در زمان اجرای مرورگر و fallback تصویری برای PNGهای غایب.
- `assets/icon-*.png` و `approved-icons.js`: هفت استیکر PNG کوچک، بهینه و شفاف که از خود تصاویر تصویری تأییدشدهٔ کاربر برش داده شده‌اند؛ برای شعله، موشک، جام، کتاب، برگ، مغز و دوستان. هنوز تمام آیکن‌ها و تصاویر سایت بازسازی دقیق از رفرنس نیستند.
- `assets/banner-moon.svg`, `assets/banner-dream.svg`, `assets/banner-castle.svg`: سه بنر SVG جدید. آستانه‌های نمایشی Unlock سطح‌های ۱/۴/۸ بدون قرارداد سروری هستند.
- `boot.js`: فایل‌های جدید را بعد از ماژول طراحی قبلی بارگذاری می‌کند؛ کد پایهٔ `app.js`, `phase2.js`, `cloud.js`, `elara-social.js`, `firestore.rules` و Admin بازنویسی یا پاک نشده‌اند.

## هنوز مسدود، تست‌نشده یا آمادهٔ انتشار نیست

- **۲۵ تصویر PNG اصلی شامل ۲۰ آواتار، چهار فریم و لوگوی اصلی** هنوز در `assets/` ریپوی توسعه کپی نشده‌اند. `approved-assets-and-site-zip.yml` در `main` برای کپی فایل‌های موجود از ریپوی عمومی و ZIP جداگانه نوشته شد، اما GitHub Actions قبل از هر Step شکست خورد. هیچ‌یک از انتقال PNG، تست CI در آن workflow یا ساخت ZIP انجام نشد. آیکن‌های استخراج‌شدهٔ کوچک با این تصاویر اصلی متفاوت‌اند.
- ZIP **تمام فایل‌های اجرایی سایت** ساخته/تحویل نشده است. مسیرهای `index.html` در ریشه و `admin/index.html` در ریپو وجود دارند، ولی فایل مستقل خروجی تأیید نشده است.
- فونت Vazirmatn از Google Fonts درخواست می‌شود و زمان اجرا بررسی می‌شود؛ موفقیت واقعی بارگذاری آن روی گوشی/PC یا آفلاین تأیید نشده است.
- کمد انتخاب‌های محلی/قفل UI دارد، اما فایل‌های اصلی، فریم روی آواتار در Preview، ذخیرهٔ میان دستگاه‌ها/پروفایل عمومی و مجوز Unlock سمت سرور هنوز کامل نیستند. Titleهای ذخیره‌شده و منطق Level عمداً مهاجرت/تغییر داده نشده‌اند.
- تصاویر مرجع هنوز هم‌ارزی دقیق پیکسلی با اجرای مرورگر ندارند؛ تست عرض‌های واقعی، RTL/LTR، Back/Refresh، جلوگیری از رگرسیون Draft و XP، دو حساب Firebase، امنیت Rules و `Missing or insufficient permissions` انجام/تأیید نشده است.

**وضعیت این مرحله: کدنویسی بخشی از ظاهر/تعامل انجام شده؛ تست مرورگری و Firebase نامشخص؛ آمادهٔ انتشار نیست.** هیچ دادهٔ کاربری عمداً پاک نشده است، اما سازگاری همۀ مسیرها بدون E2E تضمین‌شده نیست.
