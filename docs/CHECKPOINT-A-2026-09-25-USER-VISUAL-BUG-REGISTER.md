## وضعیت‌های مجاز

«رفع و آزموده شد» فقط با شواهد سناریوی دقیق و End HEAD؛ «فقط کدنویسی شد» برای تغییر بدون Browser PASS؛ «هنوز باز است» برای اختلاف باقی‌مانده؛ «منتظر فایل تصویری است» برای تصویر تأییدنشده یا بدون دسترسی upload Binary. هر گزارش بعدی باید وضعیت هر ردیف را مستقل مشخص کند. انتشار Pages با Firebase واقعی/cPanel تفاوت دارد. طراحی Checkpoint B/C و Rank/Clubs بدون تأیید بصری صریح کاربر شروع نشود.
