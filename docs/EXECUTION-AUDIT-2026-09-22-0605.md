- برای Commit مبنای قبلی `9abf850…`، اجراهای Validate `35690171395` و Deploy `35690171418` هر دو `failure` داشتند. هر دو job در API بدون step summary برگشتند (`steps: []`). دریافت لاگ job مربوط به Validate خطای ۴۰۴ `BlobNotFound` داد؛ در نتیجه علت قطعی شکست در میان خطای کد، وابستگی، تنظیمات Actions و زیرساخت قابل تشخیص نیست. هیچ خروجی تست اجراشده از این دو run در دسترس نبود.
