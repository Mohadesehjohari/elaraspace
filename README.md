# Elara Space ✦

نسخهٔ فعلی یک برنامهٔ فارسی راست‌به‌چپ برای مدیریت روزمره است. **صاحب پروژه ظاهر فعلی این شاخه (سه فایل HTML/CSS/JS ارسالی در ۲۰ سپتامبر) را انتخاب کرده است؛ بدون تأیید او بازطراحی نکنید.** رابط یک نسخهٔ واکنش‌گرا دارد، نه دو سایت مجزا برای موبایل و دسکتاپ.

## فایل‌ها و اجرا

فایل‌های `index.html`، `styles.css`، `app.js` و **`rpg.js`** باید در یک پوشه کنار هم قرار داشته باشند. `index.html` را باز کنید یا پوشه را با `python3 -m http.server 8000` سرو کنید. پروژه به Tailwind CDN وابسته نیست؛ فونت آنلاین Vazirmatn اگر بارگیری نشود، از فونت سیستمی استفاده می‌شود.

## امکاناتی که واقعاً در همین نسخه کار می‌کنند

- تسک‌ها: ساخت، ویرایش، تکمیل، حذف، چهار اولویت، تاریخ/ساعت، پوشه/برچسب، جست‌وجو و فیلتر.
- عادت‌ها: چک‌این روزانه و شمارندهٔ تداوم؛ هدف‌ها و قدم‌های قابل تکمیل؛ کتابخانهٔ سه‌قفسه‌ای؛ جعبهٔ لایتنر؛ تایمر تمرکز؛ پشتیبان JSON.
- حالت روشن/تاریک با تنظیمات و دکمهٔ بالای صفحه.
- **مأموریت‌ها و سطح:** پیشرفت مأموریت‌ها از تسک‌ها/عادت‌ها/قدم‌ها/کتاب‌های ثبت‌شدهٔ واقعی محاسبه می‌شود؛ سطح ۱ تا ۱۰ و نشان‌های مسیر بر اساس XP و سابقهٔ همان مرورگر محاسبه می‌شوند. بعضی چالش‌ها روزانه و بعضی تجمعی‌اند. این پنل XP اضافی، دوستی یا رتبهٔ ساختگی نمی‌سازد.
- چیدمان دسکتاپ و تبلت از عرض صفحه استفاده می‌کند؛ چیدمان موبایل و منوی پایین موجود حفظ شده. در گوشی، مأموریت‌ها از «بیشتر» در تنظیمات در دسترس‌اند.

## مرزهای مهم نسخهٔ فعلی

**حساب کاربری، Firebase Authentication، Firestore، یکتایی نام کاربری، درخواست دوستی، پروفایل اجتماعی، رتبه‌بندی عمومی، همگام‌سازی بین دستگاه‌ها، اعتبارسنجی سروری XP، ورزش/سلامت، هفت زبان، لوگو و آواتارهای فایل اصلی هنوز در این نسخه پیاده‌سازی نشده‌اند.** کلیهٔ داده‌های فعلی در `localStorage` مرورگر با کلید `elara_space_v1` ذخیره می‌شوند؛ آن را با یک محصول چندکاربرهٔ امن اشتباه نگیرید. داده‌های مهم را پیش از پاک‌کردن حافظهٔ مرورگر از تنظیمات پشتیبان بگیرید.

برای اجتماعی‌شدن واقعی برنامه، ابتدا باید Firebase Auth/Firestore، جداسازی اطلاعات بر اساس UID، قوانین Firestore و ثبت نام کاربری یکتا، سپس درخواست دوستی و رتبه‌بندی با امتیازِ معتبر از سمت سرور را بسازیم و روی پروژهٔ Firebase واقعی آزمایش کنیم. صرف وجود `firebaseConfig`، ساخت دیتابیس یا قرار دادن دکمهٔ Connect اتصال واقعی ایجاد نمی‌کند.

## راه پیش رو

نیازمندی‌های ارسال‌شده بسیار گسترده‌اند. [برنامهٔ مرحله‌بندی و معیارهای پذیرش](docs/PRODUCT-ROADMAP.md) مشخص می‌کند چه چیزهایی آماده، در صف، یا وابسته به زیرساخت و تأیید صاحب پروژه‌اند. این سند و کد فعلی، وعدهٔ اجرای همهٔ قابلیت‌های آن فهرست نیستند.

## آزمون‌ها

`node --check app.js && node --check rpg.js && node tests/static-check.mjs`

آزمایش مرورگریِ محلی برای اندازه‌های ۳۲۰، ۳۶۰، ۳۹۰، ۷۰۰، ۷۰۱، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل انجام شده است؛ ورود و دیتابیس واقعی هنوز تست نشده‌اند. وضعیت GitHub Actions را جداگانه بررسی کنید؛ قبلاً اجرای آن با خطایی که لاگ قابل دریافت نداشت ناموفق بود.
